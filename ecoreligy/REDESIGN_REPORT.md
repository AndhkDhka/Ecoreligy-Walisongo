# Redesign Report

- The global and mobile primary navigation now has five destinations: Home, Destinations, Peta Budaya, AR Navigation, and Info Kunjungan.
- The destination index opens filtered to the nine Wali Songo profiles, while its heritage filters remain available.
- Destination pages now link directly to a persistent, per-destination Guided flow. The Sunan Giri detail links to the available AR pilot; other destinations state that no registered target is available.
- The Leaflet map opens on the nine Wali Songo markers, labels approximate areas, can request device location, and links each marker to its profile, Guided flow, Google Maps, and directions.
- Visit information is now a general, practical guide covering respectful conduct, clothing, cleanliness, crowds, and the need to verify hours, fees, access, and facilities locally.
- The home hero now introduces the Wali Songo journey and offers direct destination and map actions. Existing culture/archive sections remain available as supporting content.
- The existing forest, ivory, gold editorial tokens and dark theme are retained. Legacy routes are left intact for old links and existing data compatibility, but are no longer primary navigation items.
